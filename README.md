## 🌟 نبذة عن المشروع (Project Overview)
**«مُـدَار»** هي أداة رقمية وتفاعلية متخصصة تم تصميمها لتمكين رواد الأعمال وأصحاب المنشآت الصغيرة والمتوسطة (SMEs) في المملكة العربية السعودية من تقييم جدوى مشاريعهم التجارية بسرعة وموثوقية عالية؛ من خلال تحويل المعايير السوقية والبيانات الميدانية إلى أرقام مالية تقديرية ومؤشرات نجاح واضحة خلال دقائق معدودة، دون الحاجة إلى خلفية مالية معقدة.

---

## 🚀 رحلة المستخدم عبر المراحل السبع (The 7-Stage Workflow)

تأخذ المنصة المستثمر في رحلة متسلسلة ودقيقة تنتهي بتقرير تنفيذي متكامل:

1. **المرحلة الأولى: لوحة الانطلاق**  
   واجهة تقديمية مريحة وسلسة تبدأ رحلة دراسة الجدوى بضغطة زر واحدة ومباشرة.

2. **المرحلة الثانية: اختيار النشاط التجاري**  
   مكتبة متنوعة من الأنشطة التجارية (مقاهي مختصة، مطاعم ومطابخ سحابية، محامص، صالونات حلاقة، خياطة رجالية، مغاسل ملابس، وغيرها)، مع اقتراح المساحة التشغيلية النموذجية والتكاليف التأسيسية المرجعية لكل نشاط.

3. **المرحلة الثالثة: اختيار المدينة والموقع المناسب**  
   تحديد المدينة (الرياض، جدة، الدمام، الخبر)، والحي، ونمط الشارع التجاري (شارع رئيسي، داخل الحي، مجمع تجاري، مركز أعمال)، مع حساب تلقائي لمتوسط إيجار المتر المربع وتكلفة الإيجار السنوي المقدرة بناءً على المساحة المدخلة.

4. **المرحلة الرابعة: تحليل ملاءمة الموقع والنشاط**  
   خوارزمية ذكية تقيس مدى انسجام النشاط المختار مع الموقع بناءً على: كثافة الحركة، القوة الشرائية لسكان الحي، معدل المنافسة، والعبء الإيجاري على ميزانية المشروع.

5. **المرحلة الخامسة: حساب الدخل والتكاليف التقديرية (مؤتمتة بالكامل)**  
   ربط حي وتلقائي لجميع الحسابات بناءً على اختيارات المراحل السابقة دون حاجة لتعديل يدوي، مع تقسيمها عبر تبويبات احترافية:
   - **النفقات التأسيسية (CAPEX):** التراخيص النظامية واشتراطات منصة بلدي والدفاع المدني، أعمال الديكور والتشطيب والواجهة المعمارية (محسوبة طردياً مع مساحة المحل)، الآلات والمعدات التشغيلية، والسيولة العاملة الأولية.
   - **المصاريف التشغيلية (OPEX):** قسط الإيجار الشهري، رواتب الكادر، تكلفة البضاعة والمواد المستهلكة (COGS)، الخدمات والمرافق، والتسويق والصيانة.
   - **المبيعات والإيرادات:** متوسط الزوار اليومي، متوسط سلة الشراء، الدخل اليومي والشهري المتوقع.

6. **المرحلة السادسة: مؤشر نجاح المشروع والمخاطر**  
   - **مؤشر الجدوى والنجاح (من ٠ إلى ١٠٠)** عبر عداد رقمي مرئي.
   - احتساب دقيق لـ **فترة استرداد رأس المال** و **نقطة التعادل الشهرية (Break-even)**.
   - **اختبار الحساسية المالي:** محاكاة فورية لتأثير انخفاض الإيرادات بنسبة (١٠٪ أو ٢٠٪) على الأرباح والاسترداد.
   - مصفوفة رصد المخاطر التشغيلية والمالية مع تصنيف مستوى الخطورة وإجراءات التخفيف المقترحة.

7. **المرحلة السابعة: التقرير النهائي والنصائح الاستراتيجية**  
   وثيقة نهائية قابلة للطباعة الرسمية والتصدير، تتضمن مؤشرات الأداء الرئيسية، جداول التدفقات، رسم بياني دائري لتوزيع المصاريف، مسار التدفق النقدي على مدى ٢٤ شهراً، وتوصيات مخصصة للنجاح في السوق السعودي.

## 🛠 التقنيات والأدوات المستخدمة (Tech Stack & Tools)

تم بناء المشروع وفق أعلى معايير الويب الحديث مع التركيز على الأداء الفائق والسرعة بدون أي تبعيات ثقيلة:

### 1. اللغات وهيكلة الواجهة (Core Technologies)
* **HTML5 دلالي (Semantic HTML):** هيكلية معيارية تراعي سهولة الوصول (Accessibility) والـ SEO، مع دعم كامل للغة العربية من اليمين لليسار (`dir="rtl"`).
* **CSS3 متقدم (Vanilla CSS):**
  - نظام متغيرات مخصص (`CSS Variables`) يرتكز على لوحة ألوان مؤسسية راقية (Steel Blue `#285172`, Sage `#415C47`, Slate `#162636`).
  - تصميم متجاوب بالكامل (`Responsive Layouts`) يدعم كافة الشاشات والأجهزة عبر `Flexbox` و `CSS Grid`.
  - تأثيرات الزجاج المصقول (`Glassmorphism`) والظلال الهادئة والبطاقات التفاعلية.
  - أنماط طباعة مخصصة (`@media print`) لتصدير التقرير النهائي كوثيقة جاهزة بجودة عالية.
* **JavaScript نقي (Vanilla ES6+):**
  - كود برمجي منظم ومفصول بنمط الكبسلة (`Modular Patterns`).
  - إدارة حالة التطبيق محلياً (`State Management`) لضمان تنقل فوري وسلس بين الخطوات السبع دون إعادة تحميل الصفحة (SPA-like experience).

### 2. المحرك الحسابي والمالي (`js/calculator.js`)
* محرك حسابات مالي متخصص (`MadarCalculator`):
  - خوارزميات حساب التكاليف والإيرادات وفق معايير المحاسبة الإدارية.
  - خوارزمية قياس مؤشر الجدوى (Feasibility Score Algorithm).
  - احتساب نقطة التعادل، هامش الربح التشغيلي، ومسار التدفق التراكمي (Cash Flow Modeling).
  - مولد ديناميكي لمصفوفة المخاطر والتوصيات الاستراتيجية.

### 3. التصوير البياني المرئي (Data Visualization)
* **رسومات متجهة تفاعلية خفيفة (Custom Pure SVG):**
  - عداد دائري تفاعلي لمؤشر الجدوى (`Radial Gauge`).
  - مخطط دائري (`Donut Chart`) لتوزيع المصاريف التشغيلية مع مفتاح الألوان التوضيحي.
  - مخطط مسار التدفق النقدي ونقطة استرداد رأس المال عبر منحنى بياني ذكي (`24-Month Cash Flow Curve`).
  *(تم تطوير جميع الرسوم بالـ SVG البرمجي دون الحاجة لأي مكتبات خارجية ثقيلة مثل Chart.js لضمان سرعة تحميل فورية).*

### 4. الهوية البصرية والتعريب الصارم (Typography & Localization)
* **خط «تجوال» (Tajawal):** مطبق بصفة إلزامية على جميع العناصر والنصوص والأرقام ورسوم SVG لضمان اتساق بصري فخم.
* **الأرقام العربية المشرقية (`٠-٩`):** تحويل ومعالجة جميع الأرقام والعملات والنسب المئوية (`٪`) لتظهر بصيغة الأرقام العربية المشرقية حصراً.
* **الصيغة العربية المرتفعة لوحدات المساحة:** استخدام `م<sup class="num-font">٢</sup>` و `لكل م<sup class="num-font">٢</sup>` بدلاً من الرموز اللاتينية.

### 5. إدارة الكود والإصدارات
* **Git & GitHub:** لتتبع التعديلات، وإدارة الفروع، والرفع المستمر.

## 💻 طريقة التشغيل محلياً (Getting Started)

المشروع مبني بأسلوب خفيف ولا يتطلب تثبيت حزم أو بيئات تشغيل معقدة:

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/anoudkanani/mudar.git
   cd mudar
   ```

2. **التشغيل:**
   - يمكنك فتح ملف `index.html` مباشرة في أي متصفح ويب حديث.
   - أو تشغيله عبر سيرفر محلي بسيط (مثل Live Server في VS Code، أو عبر بايثون):
     ```bash
     python3 -m http.server 8000
     ```
     ثم فتح الرابط `http://localhost:8000` في المتصفح.
